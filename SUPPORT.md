# Support

Lite is self-serve and intentionally has no automatic support workflow or ongoing implementation
obligation. Start with the [installation and recovery guide](https://www.crm.coach/help/launch-operator-install),
then check the repository issues for known problems.

For a bug, open a GitHub issue with a small, sanitized reproduction. Never include passwords,
tokens, session material, or customer data. For a private security or privacy report, follow
[SECURITY.md](SECURITY.md). If a gated full-edition link or download is broken, use the narrow
contact path in the delivery email or [crm.coach/contact](https://crm.coach/contact).
