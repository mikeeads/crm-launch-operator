# Security

CRM Launch Operator Lite is instruction-only. It contains no network client, credential flow, or CRM integration.

Never include real credentials, session material, or unnecessary customer data in a bug report or example file. If you find a security or privacy problem, report it privately through the contact route at [crm.coach/contact](https://crm.coach/contact) and include only sanitized reproduction details.

The public repository covers Lite. Access or delivery problems with a full edition should be reported by replying to the CRM Coach delivery email.
