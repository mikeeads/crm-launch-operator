# Contributing

Thoughtful fixes and improvements to CRM Launch Operator Lite are welcome.

Please keep contributions focused on the short, platform-neutral CRM Launch Check. Detailed HubSpot or Pipedrive implementation workflows belong to the separate full editions and are not maintained in this public repository.

Before opening a pull request:

1. Keep the conversation calm, practical, and one question at a time.
2. Preserve the rule that the skill never operates a CRM or requests credentials.
3. Make sure it still creates only `crm-launch-check.md`.
4. Do not add network calls, analytics, dependencies, or hidden redirects.
5. Run the repository validation workflow locally where practical.

For a security or privacy issue, follow [SECURITY.md](SECURITY.md) instead of opening a public issue with sensitive details.
